## Project Overview
**Gerald’s Workshop** is a professional auto-repair and maintenance service based in Polokwane, South Africa.
The aim of this website is to create an online platform that showcases the workshop’s services, allows customers to request quotes, and improves its digital presence through responsive design and SEO best practices.

## Website Goals and Objectives
- Promote Gerald’s Workshop’s mechanical services online.
- Provide an easy way for clients to **book repairs** or **enquire** about pricing.
- Display services, contact details, and workshop locations clearly.
- Optimise the site for **mobile users** and **search engines (SEO)**.

**Key Performance Indicators (KPIs):**
- Increased online enquiries by 30% within 3 months.
- Improved Google ranking for “car mechanic in Polokwane”.

## Key Features and Functionality
- Five HTML pages: Home, About Us, Services, Products/Enquiry, Contact.
- Responsive design using **CSS Flexbox and Grid**.
- JavaScript enhancements:
  - Fade-in animations on scroll.
  - Interactive accordions in Services.
  - Tabs in About Us.
  - Gallery lightbox for product images.
  - Search functionality for services.
  - Live clock in footer.
  - Enquiry and Contact forms with validation and feedback.
  - Interactive Google Maps embed.
- SEO optimisation (meta tags, alt text, keywords).

## Design Overview
- **Colour Palette:** Navy (#2c3e50), Silver (#f4f4f4), Orange Accents (#e67e22)
- **Typography:** Segoe UI for body text, default for headings.
- **Layout:** Clean, section-based with galleries and forms.
- **User Experience:** Fast loading, simple navigation, accessible forms.

## Technical Requirements
- Languages: HTML5, CSS3, JavaScript (ES6).
- IDE: Visual Studio Code.
- Version Control: Git & GitHub (private repository).

## How to Guide
1. Clone the repository: `git clone <repo-url>`
2. Open in VS Code.
3. Run locally: Use a local server (e.g., Live Server extension) or open index.html in browser.
4. For development: Edit HTML/CSS/JS files, test responsiveness on different screen sizes.
5. Deploy: Push to GitHub and enable Pages.
